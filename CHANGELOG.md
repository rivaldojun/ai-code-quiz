# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-23

First public release.

### Added

- The tool successfully reads a staged Git diff and identifies the language as Python
- The tool generates at least 3 valid multiple-choice questions for a given code change
- The web interface displays the quiz questions and allows for answer submission
- The tool operates entirely offline without attempting to connect to external servers
